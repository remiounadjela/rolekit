# RoleKit

Read `AGENTS.md` and `skills/tailor-cv/SKILL.md`.
For a new candidate's CV, notes, or blank-canvas setup, read `skills/onboard-candidate/SKILL.md`.
For source discovery and recurring search/application work, read `skills/job-search/SKILL.md`.
Use one candidate workspace established automatically during onboarding or explicitly supplied for
resumption. Private records may be in local RoleKit user data or ignored `workspaces/`.
The `/tailor-cv` command and `.claude/skills/tailor-cv` point to the same canonical skill.
The `/job-search` command and `.claude/skills/job-search` point to the companion search skill.
The `/onboard-candidate` command and `.claude/skills/onboard-candidate` point to the intake skill.
