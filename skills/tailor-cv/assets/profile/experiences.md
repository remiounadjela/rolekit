# Experience library

This is the reusable record for this candidate, separate from a one-page CV.
Preserve useful detail and cite original input extracts or supporting records. Remove these
prompts as real experiences are added; an empty template is not evidence.

## Experience entry shape

Use stable IDs such as E001. Include only fields relevant to the supplied experience; missing
details can stay unknown. Employment, projects, education, volunteering, and other experience count.

- ID and name:
- Organization / context:
- Official title, if any:
- Dates (with any uncertainty):
- What happened / problem:
- My contribution (distinct from the team's work):
- Responsibilities and scope (direct reports / functional reach separately):
- Tools and skills actually used:
- Outcomes (unit, time window, measured vs estimated vs forecast):
- Attribution: candidate_reported / documented / uncertain / conflicting
- Sources: workspace-relative path plus page, paragraph, line, or section
- Open questions / wording to avoid:

Keep qualifiers and source disagreements. A source CV or transcript is a candidate report, not
independent verification. Cite the original behind a derived summary; do not use a generated CV
to corroborate the same summary.
